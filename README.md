# GreatKingdom
Game designed by Lee sae dol. <br>
Adopted simple dqn + mcts engine. <br>
Supports full C++ implementation of dqn + mcts. <br>
Requires libtorch + CUDA. <br>
Supported function beyond simple dqn + mcts : <br>
1. Multi-thread support for training.
2. Evaluation Cache
3. Transposition table

Colab sample link could be found on greatkingdom.ipynb file.
